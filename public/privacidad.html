Política de privacidad de Jarvis

Última actualización: 27 de octubre de 2026.

Jarvis es un asistente personal de uso privado, operado por Alejandro Paz (Villavicencio, Colombia) para su propio uso. No es un servicio abierto al público: el acceso está protegido con una clave.

Qué datos usa

Con autorización del titular de la cuenta, Jarvis accede a Google Calendar (consultar, crear y eliminar eventos) y a Gmail (buscar, leer y enviar correos) únicamente para responder a las solicitudes que el propio titular le hace.

Cómo los usa

Los datos se procesan solo para cumplir cada solicitud. El texto de las solicitudes y los resultados necesarios se envían al modelo de lenguaje Claude (Anthropic) para generar la respuesta. Jarvis no vende, comparte ni usa estos datos con fines publicitarios, y no los transfiere a terceros fuera de lo necesario para prestar el servicio.

Qué se guarda

En el servidor privado del titular se guardan el token de acceso de Google, el historial reciente de conversación y las notas que el titular pide recordar. El titular puede borrarlos en cualquier momento, y puede revocar el acceso de Google desde myaccount.google.com/permissions.

Uso de datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
